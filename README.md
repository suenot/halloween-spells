# Хэллоуин-Заклинания

Сайт и игра: слово + движение палочкой (школа "Волшебники") или ручные печати (школа "Шиноби").

## Запуск
```bash
npm start            # http://localhost:5173
npm test             # логика: оценка, жесты, турнир, данные
scripts/fetch-vendor.sh   # один раз, если нет public/vendor/mediapipe (камера и руки)
```
Открывать в **Chrome** на MacBook: камера и распознавание речи работают на `localhost`.

## Что нужно знать ведущему
- Руки и камера работают без интернета (MediaPipe лежит в `public/vendor/`).
- **Слова слушают нейросети прямо в браузере** (по умолчанию Zipformer, без интернета и без Google; запасной вариант Web Speech в Chrome). Выбор движков: страница `/asr-lab.html` или кнопка "🎙 Слух" в игре. Если слух не работает, ведущий жмет кнопки: "Засчитать (1)", "Почти (2)", "Еще раз (R)", "Дальше (Enter)".
- Оценка щадящая по умолчанию (переключатель под экраном игры).
- Палочка: Игра, "Показать палочку камере", нажми на палочку в картинке. Без калибровки следим за указательным пальцем.
- Результаты пишутся в `data/` после каждого хода; перезагрузка страницы ничего не теряет.

## Режимы
Соло-турнир, общий сюжет по ролям, команды, хор против монстров.

## Данные (`data/*.json`)
`players`, `teams`, `spells`, `stories`, `universes`, `monsters`, `tournaments`, `current`. Роли, классы, расы, факультеты, рост и вес игроков редактируются в разделе "Игроки". Вселенные: Гарри Поттер, Наруто, Властелин Колец.

## Распознавание речи (`public/js/engine/asr/`)

Движки работают в Web Worker, чтобы не тормозить камеру. Можно включить несколько сразу: игра берет лучшее совпадение, а совпадение считается по написанию и по звучанию (`matchScore` в `core/fuzzy.js`).

| Движок | Размер | Заметки |
|---|---|---|
| Zipformer small (sherpa-onnx) | 29 МБ | потоковая, по умолчанию |
| T-One (sherpa-onnx) | 144 МБ | потоковая, телефонная речь |
| GigaAM v3 (sherpa-onnx) | 225 МБ | точная, но решает по фразе и медленная в WASM |
| Vosk small ru | 46 МБ | потоковая, только локальные файлы |
| Whisper tiny (transformers.js) | 41 МБ | по фразам |
| Web Speech | 0 | только Chrome, звук уходит в Google |

Файлы моделей не лежат в git: `scripts/fetch-asr.sh` (все в `public/vendor/asr/`). На хостинге собирается только `fetch-asr.sh runtime`, модели sherpa и Whisper подтягиваются с Hugging Face. Лаборатория `/asr-lab.html` гоняет движки на записях (`public/lab-samples/`) или на микрофоне и показывает текст, совпадение и задержку.

## Движения рук (`core/motions.js`, `engine/handfx.js`)

Кроме поз-печатей и росчерков палочкой игра читает движения рук по ряду кадров камеры: `charge` (сжать кулак и держать), `spin` (водить ладонью кругами), `push` (резко подать ладонь к камере), `spread` (развести руки), `crush` (ладонь в кулак), `shake` (дрожь кулака). Шаги можно ставить в `gesture` заклинания рядом с остальными, например Расенган это `spin`, `push`. Пока игрок двигает рукой, над ладонью растет живой шар и вспыхивает разряд, когда движение засчитано. Демонстрация в книге и в игре прогоняет искусственную ладонь через тот же детектор и те же эффекты, поэтому показ не расходится с распознаванием. Пороги лежат в `MOTION_CFG`. Проверено на синтетических кадрах; на живой камере и детских руках не проверено, пороги, скорее всего, придется подкрутить.

## Звук и музыка

Все звуки и музыка синтезируются в браузере (Web Audio), файлов нет, работает офлайн. Справа в шапке: 🔊 выкл звука, 🎵 выкл музыки, громкость. Музыка стартует после первого клика (правило браузера), меняется по экранам (меню, игра, бой с монстрами, рейтинг) и приглушается, пока микрофон слушает игрока. Логика музыки: `public/js/core/music.js`, синтез: `public/js/engine/audio.js`.

## Анимации жестов и эффекты заклинаний

- Ролики рук (Blender, процедурная анатомия кисти): `tools/blender/hands.py`, сборка `tools/blender/build_gestures.sh` (нужны Blender и ffmpeg). Результат: `public/assets/gestures/*.webm` (VP9 с прозрачностью, работает в Chrome) и `w_*.json` с траекторией кончика палочки для светящегося следа.
- Проигрыватель: `public/js/ui/demo.js`, используется в книге заклинаний и на экране игры.
- Эффекты: `public/js/engine/spellfx.js`. У каждого заклинания в `data/spells.json` свой список слоев `fx`, первый слой (герой) уникален. Превью всех: `/fxlab.html`.
- Интерфейс: стартовый экран `#/`, выбор героев и редактор, элементы управления в `public/js/ui/controls.js`.

## Источники заклинаний

- Волшебники: Harry Potter Wiki (harrypotter.fandom.com): Lumos, Reparo, Aqua Eructo, Incendio, Glacius, Wingardium Leviosa, Stupefy, Defodio, Protego, Expelliarmus, Obscuro, Expecto Patronum.
- Шиноби: Школа техник Наруто (jut.su/by-episodes/): русские названия техник и страницы "Как сделать" с цепочками печатей; оригинальные названия сверены с Narutopedia (naruto.fandom.com). В игре шесть жестов-печатей: Тигр, Свинья, Собака, Овца, Обезьяна, Змея. Из цепочки на сайте берутся печати этого набора, не больше четырех, в исходном порядке. У техник без ручных печатей (Великий порыв, Мгновение, Растворение в тумане, Ледяные зеркала демонов) дан один простой жест.

## Референс-ролики (локально)

`references/search_hp.py` ищет короткие ролики с заклинаниями Гарри Поттера, `references/fetch_hp.py` скачивает выбранные (yt-dlp, 480p, нужны куки Chrome) в `references/harry-potter/<id>/` и пишет `index.json`. Это чужой контент: папка в `.gitignore`, в репозиторий и на Vercel не попадает. Локальный `server.mjs` отдает файлы по `/refs/harry-potter/` (с Range), а книга заклинаний и экран хода показывают их обычным `<video>` ("Как в кино"). Нет файлов, нет блока.
